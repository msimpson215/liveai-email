# Marty's career — raw capture

Talk into this file. Nothing here is live. It gets edited into page copy and
into the voice profile only after Marty reads it back and approves.

**How to dictate without losing it:** put the cursor in the section, then
Windows key + H (or the dictation key on a Mac). The words type themselves in
as you speak, so nothing can evaporate when you send. Stop and start whenever —
this is a file, not a message.

Don't worry about wording, order, or repeating yourself. Ramble. Editing is
cheap; the stories are not.

## Ground rules before anything goes live

These exist because **whatever lands on a page also lands in the AI's mouth.**
The talk button reads from `server/marty-cv.js`, so every fact added here is
something the AI will state out loud, with confidence, to a stranger.

| Rule | Why |
|------|-----|
| No number goes live unconfirmed | The Medical Testing Center was published at $1.2M and was actually $4M. Caught by Marty, not by anyone else. |
| No private individuals named without permission | Partners, tenants, employees, patients, family. |
| Nothing identifying from the public-health years | The HIV/AIDS-era work is the one area carrying real legal weight. |
| Litigation stays at public record | The Overview already says the file does not invent the case name. That holds. |
| Community work stays under-claimed | Two children's-house programs, a theater donation, and a 501(c)(3) restaurant fundraising *proposal*. Not more. |
| Never characterize another party | Not "say nothing negative" — say nothing *about them*. Businesses that closed, closed. Deals that went sideways, went sideways. Flat, then move on. |
| Published work gets cited, not reproduced | See the Business Journal note at the bottom. |

## Note on the Business Journal photo

Scanning the printed page and posting it is the paper's copyright, not ours, and
it is exposure we do not need for no gain.

What a serious CV does instead is **cite** it — publication, date, headline, and
a link, as an entry on the Media page that already exists. Same credibility,
nothing to defend.

If the clipping itself is wanted as an image, that requires written permission
from the publication. Worth asking for; not worth assuming.
