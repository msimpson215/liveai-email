Stay on Gmail — tiny popup

Email links cannot shrink the window. Browsers block that. This extension intercepts the link on Gmail and opens a 236px popup instead of a full tab.
  1. Download extension folder: liveai-email.zip
  2. Unzip → open the extension folder
  3. Chrome → chrome://extensions
  4. Turn on Developer mode (top right)
  5. Load unpacked → select the extension folder
  6. Open Gmail → click orb in your email → small window, Gmail stays

A small yellow orb also appears bottom-right in Gmail. Click anytime.
